# StokAman_Kelompok 7

Aplikasi inventori stok gudang UMKM menggunakan **PHP Native** dengan CI/CD pipeline **Jenkins** dan **Trivy**.

## Stack

## Fitur Utama
* CRUD produk, kategori, dan pemasok
* Transaksi barang masuk & keluar (FIFO, tanpa stok minus, SKU unik)
* Kartu stok & peringatan stok minimum
* Endpoint `GET /health`
